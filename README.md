# دست‌خط من — ساخت فونت فارسی TTF از دست‌خط (PWA)

برنامه‌ای کاملاً سمت‌کاربر (بدون سرور، حساب کاربری یا API) برای تبدیل دست‌خط به فایل **TTF** با اتصال حروف فارسی (GSUB: isol/init/medi/fina و GPOS: curs) و پشتیبانی از نیم‌فاصله.

## روند استفاده (Chrome اندروید)
۱. ساخت فونت جدید. ۲. برگهٔ نمونه‌نویسی را چاپ کنید (PNG/PDF) و داخل خانه‌ها با خودکار بنویسید. ۳. ورود تصویر: دوربین با کادر راهنما یا گالری؛ گوشه‌ها خودکار پیدا می‌شوند و قابل اصلاح‌اند. ۴. آستانه را تنظیم و استخراج کنید. ۵. گلیف‌ها را بررسی، ویرایش و تأیید کنید. ۶. پیش‌نمایش زنده. ۷. دریافت TTF، پشتیبان ZIP و گزارش.
نکته: در شکل‌های ابتدا/میان/انتها، خط اتصال را تا لبهٔ خانه ادامه دهید تا حروف به هم بچسبند.

## ساختار
index.html · sw.js · manifest.json · icon-*.png · font-engine/ttf-builder.js (TTF، GSUB، GPOS) · image-engine/image-engine.js (پرسپکتیو، آستانه، برداری‌سازی، گوشه‌یابی) · workers/image-worker.js · storage/zip.js · tests/ · docs/

## تشخیص جدول (نسخهٔ اصلاح‌شده)
جدول واقعی چاپ‌شده مستقل از گوشه‌های کاغذ تشخیص داده می‌شود: نرمال‌سازی نور/سایه ← تشخیص و اصلاح چرخش ← یافتن خطوط عمودی/افقی ← انتخاب ۹ خط عمودی و (۱۱ یا ۸) +۱ خط افقی هم‌فاصله (خط جاافتاده بازسازی و خط اضافی مثل لبهٔ کاغذ حذف می‌شود) ← ناحیهٔ هر خانه از مختصات واقعی جدول. اگر تشخیص مطمئن نباشد، پیام فارسی نمایش داده می‌شود و استخراج تا تأیید دستی مرز جدول (۴ دایرهٔ قابل‌کشیدن) غیرفعال می‌ماند.
توجه: صفحهٔ ۲ اکنون ۸ ردیف کامل رسم می‌کند (قبلاً ردیف آخر ناقص بود)؛ برگهٔ قدیمی صفحهٔ ۲ هم با بازسازی خط جاافتاده پشتیبانی می‌شود.

## تصمیم‌های فنی
- به‌جای Pyodide/FontTools، سازندهٔ TTF با جاوااسکریپت خالص نوشته شد (بدون وابستگی و آفلاین).
- پشتیبان ZIP بدون فشرده‌سازی است؛ بازیابی ZIP/JSON ساخته‌شدهٔ همین برنامه.
- دوربین با getUserMedia؛ در صورت نبود مجوز، انتخاب از گالری.
